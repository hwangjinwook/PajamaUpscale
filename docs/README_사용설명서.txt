파자마업스케일 (PajamaUpscale) v1.0.0 — 사용설명서
==================================================

이미지를 AI로 2배·3배·4배 선명하게 키우는 윈도우 프로그램이에요.
그냥 늘리는 것과 달리 흐릿해진 선과 질감을 AI가 새로 그려 주고,
인터넷에 올리지 않고 이 컴퓨터 안에서만 처리해요.

새 버전: https://github.com/hwangjinwook/PajamaUpscale/releases/latest


[ 들어 있는 파일 ]

  파자마업스케일.exe        프로그램 본체
  engine\                   AI 엔진(Real-ESRGAN)과 모델 — exe 와 꼭 같은 폴더에 두세요
  README_사용설명서.txt     이 파일
  THIRD_PARTY_LICENSES.txt  함께 들어 있는 AI 엔진·라이브러리의 라이선스


[ 실행하기 ]

  1. zip 을 원하는 폴더에 압축을 풀어요. (zip 창 안에서 바로 실행하면 engine 폴더를 찾지 못해요)
  2. 파자마업스케일 폴더의 파자마업스케일.exe 를 두 번 눌러요.

  - 설치할 것도, 파이썬도, 인터넷 연결도 필요 없어요. 확대는 그래픽카드(Vulkan)로 해요.
  - 다른 곳으로 옮길 때는 파자마업스케일 폴더를 통째로 옮기세요. exe 만 옮기면 확대가 안 돼요.
  - 「Windows의 PC 보호」 창이 뜨면 「추가 정보」 → 「실행」을 누르세요.
    디지털 서명이 없는 프로그램이라 나오는 안내예요.


[ 사용법 ]

  1. 이미지나 폴더를 창에 끌어다 놓거나, 「＋ 이미지 추가」 / 「📁 폴더 추가」를 눌러요.
     폴더는 하위 폴더의 이미지까지 들어와요. (PNG · JPG · WebP · BMP · TIFF · GIF)
  2. 아래에서 골라요.
     - 이미지 종류: 사진·실사(가장 선명·자연스러움) / 그림·애니·일러스트 / 빠르게(많은 장을 빨리, 그림용)
     - 배율: 2배 · 3배 · 4배
     - 형식: PNG(투명 유지) · JPG(투명은 흰 바탕) · WebP
     - 저장 위치: 원본 옆 「업스케일」 폴더(기본) / 원본과 같은 폴더 / 직접 고르기
  3. 「✨ 업스케일 시작」을 눌러요. 장마다 진행률이 보이고, 「■ 멈추기」로 언제든 멈출 수 있어요.
     멈춰도 그때까지 끝난 결과는 남아요.
  4. 결과 보기
     - 결과를 두 번 누르면 열려요.
     - 결과를 오른쪽 클릭 → 「🔍 원본과 비교하기」: 가운데 선을 끌어 왼쪽(원본)과 오른쪽(결과)을 비교해요.
       휠로 확대하고, 오른쪽 버튼으로 끌어 옮겨요.
     - 「📂 결과 폴더 열기」를 누르면 마지막 결과가 들어 있는 폴더를 보여 줘요.
  - 목록에서 빼려면 「빼기」(또는 Delete 키), 모두 지우려면 「목록 비우기」.


[ 알아 둘 점 ]

  - 결과는 「원래이름_x4.png」처럼 저장되고, 같은 이름이 있으면 (2), (3)을 붙여
    원본이나 먼저 만든 결과를 덮어쓰지 않아요.
  - 휴대폰 사진의 회전을 바로잡아 확대하고, 색 정보·해상도 정보는 결과에도 남아요.
  - 투명한 PNG 는 투명한 채로 커져요. 움직이는 GIF·WebP 는 첫 장면만 확대해요.
  - 한글이나 특수문자가 들어간 파일 이름도 괜찮아요.
  - 설정은 exe 옆 settings.json 에 저장돼서 다음에 켜도 그대로예요.


[ 잘 안될 때 ]

  - 「너무 크다」는 안내가 뜨면: 결과가 약 4억 화소(가로세로 2만 화소 정도)를 넘으면
    메모리가 모자랄 수 있어 미리 막아요. 배율을 한 단계 낮춰 주세요.
  - 그래픽카드 오류가 나면: 「그래픽카드 대신 CPU 로」를 켜고 다시 해 보세요(많이 느려요).
  - 확대가 아예 시작되지 않으면: exe 옆에 engine 폴더가 있는지 확인해 주세요.


[ 새 버전으로 바꾸기 · 지우기 ]

  - 새 버전: 프로그램을 끄고, 새 zip 의 파자마업스케일 폴더로 통째로 바꿔요.
    설정을 이어 쓰려면 옛 폴더의 settings.json 을 새 폴더에 복사해 두세요.
  - 지우기: 설치 기록이 없어서 파자마업스케일 폴더만 지우면 돼요.
